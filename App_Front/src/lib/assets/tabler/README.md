# Tabler Icons

Douze icônes SVG issues de Tabler Icons v3.35.0, conservées sans modification :
https://github.com/tabler/tabler-icons/tree/v3.35.0/icons/outline

Licence MIT et attribution : voir `LICENSE` dans ce dossier.
Les fichiers sont servis localement par Vite, sans dépendance npm ni requête vers un service d'icônes.
Le composant Icon utilise ces SVG comme masques pour suivre la couleur du thème.
La copie publique `public/licenses/tabler-icons.txt` doit rester identique à `LICENSE` ; Vite la distribue dans le build.
